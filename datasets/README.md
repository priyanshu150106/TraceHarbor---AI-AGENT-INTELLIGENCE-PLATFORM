# TraceHarbor Datasets

Golden test datasets and adversarial prompt suites for evaluation and security testing.

## Planned Datasets (Phase 3 & Phase 4)

- **`qa-golden-dataset.json`**: Question-answering evaluation pairs with ground truth outputs.
- **`tool-use-eval-dataset.json`**: Multi-turn tool calling accuracy and argument validation.
- **`adversarial-injection-suite.json`**: Prompt injection and jailbreak test cases.
- **`pii-leakage-suite.json`**: Sensitive data exfiltration attack scenarios.
